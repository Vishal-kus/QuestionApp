# UGC NET 2025 Paper - Computer Based Test (CBT) Series

An authentic National Testing Agency (NTA) UGC NET 2025 Online Mock Test Series web application built with React, Vite, and modern CSS.

## 🚀 Key Features

- **Official NTA CBT Exam Interface**: Exact visual replica of the official NTA examination engine, candidate name display, and live countdown timer.
- **Full 100 Questions Dataset**: 100 comprehensive questions covering all 10 syllabus units of UGC NET Computer Science & Applications (Paper II).
- **Dynamic Question Shuffling**: Every time you start or re-take the examination, questions are randomized using the Fisher-Yates shuffle algorithm.
- **NTA Question Palette**: Real-time status legend tracking (Answered, Not Answered, Marked for Review, Answered & Marked for Review, Not Visited) with direct question jump functionality.
- **Pre-Submission Summary Modal**: Official summary counts before final submission.
- **Detailed Result & Solution Analysis**:
  - Scorecard (out of 200 Marks, +2 / 0 marking scheme).
  - Accuracy and time-spent analytics.
  - Unit-wise performance breakdown.
  - Step-by-step reasoning and mathematical explanations for all 100 questions.
  - Filterable by All, Correct, Incorrect, and Skipped.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Icons**: Lucide React
- **Celebration**: Canvas Confetti
- **Styling**: Pure CSS design tokens adhering to NTA CBT interface standards

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Vishal-kus/QuestionApp.git

# Navigate to project folder
cd QuestionApp

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
